# startpage

Vendored from [kencx/startpage](https://github.com/kencx/startpage) (MIT).

Customised for this machine:

- Recoloured from Gruvbox to the Vague palette, to match the rest of the setup
- Font switched to JetBrainsMono Nerd Font Mono
- Links replaced with this machine's quickmarks
- Google search box added at the top of the right column

Everything else — layout, spacing, the blinking cursor, `cat.gif` — is upstream's.

Original cat gif credit: [avogado6](https://twitter.com/avogado6/status/1165595520967954432)
